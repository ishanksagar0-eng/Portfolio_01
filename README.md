# Personal Portfolio

A clean, modern, dark-themed portfolio website.

## Files included

| File | Purpose |
|------|---------|
| `index.html` | Home page – hero, projects, contact form |
| `about.html` | About page – journey, skills, quick info |
| `style.css` | Shared styles (responsive + accessible) |
| `layout.text` | Layout documentation |
| `performance.md` | Performance tips & checklist |
| `README.md` | This file |

## Quick start

1. Open the folder in any code editor.
2. Replace all `[Your Name]` and placeholder text with your real info.
3. Update social links in the footer.
4. Add real project images and links.
5. Open `index.html` in a browser to preview.

## Contact form

The form currently shows a demo success message (no data is sent).

To make it work:

- **Formspree** → change `action` to your Formspree endpoint
- **Netlify Forms** → add `netlify` attribute and deploy on Netlify
- **EmailJS** → add their small script

Fields:

- Name
- Subject
- Message

## Customization tips

- Colors → edit CSS variables in `:root` inside `style.css`
- Font → change the Google Fonts link + `--font` variable
- Projects → edit the three cards in `index.html`
- Add more pages if needed (copy the header/footer pattern)
