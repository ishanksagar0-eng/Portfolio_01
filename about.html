About This Project

The philosophy behind effortless responsive design.

Why "Effortless"?

Responsive design used to mean writing dozens of media queries and fighting with fixed widths. Today, with CSS Grid, Flexbox, and viewport-relative units, we can build layouts that just work at every size.

This site is a living example. Every component — from the navigation to the feature grid — is built with mobile-first principles and modern CSS. There are only 3 media queries in the entire stylesheet.

  • ✅ Flexbox for one‑dimensional layouts (nav, cards)
  • ✅ CSS Grid for two‑dimensional page structures
  • ✅ clamp() for fluid typography
  • ✅ auto-fit / minmax() for self‑adjusting grids

📊 Tech Stack

  • HTML5
  • CSS3 (Flexbox + Grid)
  • Vanilla JavaScript (hamburger)
  • No frameworks needed

🎯 Core Principles

  • Mobile‑first
  • Progressive enhancement
  • Performance by default
  • Accessibility (ARIA labels)
